TOPIC
    about_PSImageConverter

SHORT DESCRIPTION
    Cross-platform conversion of HEIC/HEIF images, powered by Magick.NET.

LONG DESCRIPTION
    PSImageConverter converts HEIC/HEIF images (for example photos taken with
    an iPhone) to JPEG, PNG, WebP, TIFF, BMP, GIF or AVIF and reads their
    metadata. The Magick.NET library and its native ImageMagick build are
    bundled with the module, so no codecs need to be installed. It requires
    PowerShell 7.4 or later and runs on Windows, Linux and macOS (x64 and
    arm64; on Alpine/musl Linux x64 only).

    Writing HEIC files is not supported, because the bundled ImageMagick build
    does not contain an HEVC encoder.

EXAMPLES
    PS C:\> ConvertFrom-Heic -Path .\IMG_1234.HEIC

    PS C:\> Get-ChildItem -Path C:\Pictures -Filter *.heic | ConvertFrom-Heic -Format Png

    PS C:\> Get-ChildItem -Path C:\Pictures -Filter *.heic | Get-HeicInfo
